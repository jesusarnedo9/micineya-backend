# Plataformas e insignias

## Recomendaciones

Cada resultado recomendado puede incluir `plataformas`, con los servicios por suscripción disponibles en Argentina que también forman parte de las preferencias del usuario. La ausencia temporal de disponibilidad no falla ni retrasa la entrega con un error: devuelve una lista vacía. Las respuestas se conservan en memoria durante doce horas para reducir consultas repetidas a TMDB/JustWatch.

## Logros

`ProgresoResponse.insignias` se deriva del historial real y también forma parte del progreso del perfil público. No se agrega un contador manipulable ni una tabla de premios.

| Código | Serie TMDB | Condición |
| --- | ---: | --- |
| `SERIE_TRONOS` | 1399 | Temporadas 1 a 8 |
| `SERIE_QUIMICA` | 1396 | Temporadas 1 a 5 |
| `SERIE_CICLO` | 70523 | Temporadas 1 a 3 |

Editar una reseña no duplica logros. Quitar una temporada necesaria vuelve a bloquear la insignia. No hay cambios de esquema, nuevas variables ni datos privados expuestos.
